# یافته‌ها و حدود شواهد G0

## اصلاح‌شده
- آزمون Tab تقویم نشان داد فوکوس می‌تواند به chrome مرورگر برود؛ گردش صریح فوکوس در همهٔ dialogها اضافه شد. بازآزمایی پاس است.
- بعد از ثبت نشانگر، تازه‌سازی متن مطالعه انتخاب گزیده را می‌زدود؛ متن فقط وقتی عوض می‌شود دوباره در DOM قرار می‌گیرد و پیام ثبت پس از تازه‌سازی نمایش داده می‌شود. آزمون گزیده روی منبع و بسته پاس است.
- بازچینی در CSS zoom ابتدا فضای کم به محتوا می‌داد؛ container query جای media query وابسته به viewport را گرفت. تصاویر جدید خوانایی و نبود اسکرول افقی را نشان می‌دهند.
- آزمون واردکردن استایل inline به‌علت CSP رد شد؛ سیاست محصول تضعیف نشد و ابزار آزمون از CSSOM برای شبیه‌سازی fallback قلم استفاده کرد.
- استخراج PDF با ابزار pdftotext موجود نبود؛ pypdf نصب‌شده استفاده شد. پایان‌خط CRLF مطابق رفتار textarea به LF تبدیل می‌شود؛ سایر نویسه‌ها/اشکال نمایشی PDF عین متن ورودی حفظ شدند و NFKC فقط شاخص جست‌وجو را تغییر داد.

## باز / اجرا‌نشده
- پروفایل‌های داده و مرورگر مستقل آزمایش شده‌اند؛ حساب Windows تازه و دستگاه ویندوزی دوم آزمایش نشده‌اند.
- درخواست‌های خارجی مرورگر در سناریوی بسته مسدود شدند و محصول فقط منابع محلی دارد؛ کابل/شبکهٔ کل رایانه قطع نشده است.
- بزرگ‌نمایی ۲۰۰٪ با CSS zoom و بازچینی آزموده شد؛ تنظیم واقعی زوم مرورگر و Windows scaling مستقل هنوز دستی بررسی نشده‌اند.
- درخت دسترس‌پذیری و صفحه‌کلید آزموده شده‌اند؛ دور کامل Windows Narrator اجرا نشده است. ادعای انطباق کامل WCAG نداریم.
- ایران‌سنس نصب‌شده و fallback اجباری وزیرمتن با CDP تأیید شدند؛ پروفایل Windows واقعاً فاقد ایران‌سنس ساخته نشد.
- دو PDF مصنوعی متعلق به آزمون ساخته، رندر و از متن استخراج‌شدهٔ آن‌ها با Clipboard واقعی Paste شد؛ انتخاب/Copy دستی از PDF viewer و PDFهای واقعی مالک هنوز بررسی نشده است. بعضی استخراج‌گرها ترتیب یا واژه‌های متن ترکیبی را ناقص استخراج می‌کنند؛ برنامه OCR یا اصلاح خودکار متن PDF ندارد.
- ZIP محلی بدون Mark-of-the-Web اجرا شد. SmartScreen برای دانلود واقعی از اینترنت و امضای تجاری بررسی/تهیه نشده‌اند؛ نباید نتیجهٔ «بدون هشدار Windows روی همهٔ دستگاه‌ها» ادعا شود.
- ارتقا در G0 تعویض دو کپی سازگار از همین build است؛ انتشار اجرایی قبلی مستقل وجود ندارد و migration/rollback به G5-پایانی منتقل شده است.
- پیش‌نویسِ داخل تب پس از crash مرورگر تضمین دوام ندارد. crash تب کثیف ممکن است خروج ایمن را تا بستن دستی فرایند نگه دارد؛ راهنما توضیح دارد.

این موارد برای بازخورد مالک باز هستند و به‌عنوان تست پاس ثبت نشده‌اند. قابلیت‌های صوت و بازیابی طبق درخواست مالک خارج از دامنهٔ G0 هستند، نه شکست آزمون.
