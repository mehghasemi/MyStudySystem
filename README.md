# سیستم مطالعه من — G0-r1

نمونهٔ آزمایشی ویندوز با دادهٔ ساختگی؛ مطابق محتوای ۳٫۱۲ سند تولید. فقط G0: ثبت متن ساده، مطالعهٔ دو کتاب نمونه، گزیده، مرور نمایشی، جست‌وجوی فارسی، انتخابگر جلالی، ذخیرهٔ SQLite و خروج کامل.

## دریافت نسخهٔ اول
[نسخهٔ آزمایشی G0-r1 و ZIP ویندوز](https://github.com/mehghasemi/MyStudySystem/releases/tag/G0-r1)

این انتشار فقط G0 است؛ موارد آزمون دستی باز در docs/TEST_MATRIX.md ثبت شده‌اند.

## اجرای سادهٔ بسته
۱. ZIP را با Extract All در یک پوشهٔ محلی قابل‌نوشتن، مثلاً `D:\MyStudyTest`، باز کنید؛ از داخل ZIP اجرا نکنید.
۲. در پوشهٔ `app` روی `MyStudySystem.exe` دوبار کلیک کنید. برنامه در مرورگر پیش‌فرض باز می‌شود؛ Chrome یا Edge لازم است. Python همراه بسته است و نصب یا اینترنت لازم ندارد.
۳. «ایجاد دادهٔ آزمایشی» را بزنید. دو کتاب و یادداشت‌های ساختگی ایجاد می‌شوند؛ دیتابیس آماده داخل ZIP نیست.
۴. برای بستن از «خروج کامل» استفاده کنید. بستن تب به‌تنهایی فرایند محلی را متوقف نمی‌کند.

پیش‌نیاز: Windows ده یا یازده ۶۴بیتی، Chrome/Edge و .NET Framework 4.x ویندوز برای راه‌انداز. بسته امضای تجاری ندارد؛ رفتار SmartScreenِ فایل دانلودشده باید روی دستگاه مقصد بررسی شود. فایل را فقط از مسیر همین تحویل اجرا کنید.

## چه چیزهایی را امتحان کنید؟
- یک متن فارسی/English را در ثبت سریع بچسبانید، تاریخ و ساعت شمسی انتخاب و ذخیره کنید.
- کتاب نمونه را از صفحهٔ ۴۷ باز کنید، صفحه را تغییر دهید و یک عبارت را به‌عنوان گزیده ثبت کنید.
- در مرور آزمایشی ابتدا از حافظه تلاش کنید؛ سپس مطلب را نمایش دهید. سه انتخاب فقط پیش‌نمایش‌اند و برنامهٔ مرور واقعی نمی‌سازند.
- یک یادداشت را در دو تب باز کنید؛ بعد از ذخیرهٔ تب اول، ذخیرهٔ تب دوم باید تعارض نشان دهد و نوشته را حفظ کند.
- برنامه را کامل ببندید و دوباره باز کنید؛ متن، تاریخ، جای مطالعه و تم باید باقی باشند.

## داده و محدوده
`app` فایل‌های قابل تعویض است؛ `data` هم‌سطح آن در نخستین اجرا ساخته می‌شود. داده وابسته به پوشهٔ کاری میانبر نیست. بسته را در OneDrive/Dropbox/مسیر Sync یا Program Files اجرا نکنید؛ برای مسیرهای همگام‌سازی ناشناخته خودتان بررسی کنید.
این نمونه برای دادهٔ ساختگی است. صوت، بکاپ و بازیابی وجود ندارند و به G5-پایانی منتقل شده‌اند. مدیریت کامل منبع، مرور زمان‌بندی‌شده، سهمیه و Undo آن، هنوز پیاده‌سازی نشده‌اند. انتخابگر تاریخ فعلاً ۱۳۹۰ تا ۱۴۵۰ و منطقهٔ ساعت تهران را پوشش می‌دهد.

## اجرای توسعه و بررسی
فرمان‌ها از ریشهٔ پروژه در PowerShell اجرا می‌شوند؛ جزئیات نتیجهٔ واقعی در `docs/TEST_MATRIX.md` است.

```powershell
python -X utf8 -m unittest discover -s tests -v
node tests\browser.cjs
node tests\quality.cjs
python -X utf8 scripts\build.py
python -X utf8 tests\package_lifecycle.py
```

اجرای دستی توسعه با دادهٔ جدا:
```powershell
python -X utf8 app\main.py --data .test-runs\manual
```

آزمون مرورگر از Playwright نسخهٔ نصب‌شدهٔ Node استفاده می‌کند؛ مسیر دلخواه با متغیر `PLAYWRIGHT_MODULE` قابل تعیین است. راهنمای webapp-testing برای Python خوانده شد، اما نصب بستهٔ Python از شبکه کامل نشد؛ آزمون‌ها با همان موتور Playwright در Node اجرا می‌شوند. Runtime محصول فقط کتابخانهٔ استاندارد Python است. نسخهٔ دقیق ابزارها و هش فایل‌ها در `toolchain.lock.json` و `BUILD_MANIFEST.json` ثبت می‌شود. اسکریپت build فقط از فهرست مجاز فایل‌ها بسته می‌سازد.

## تعویض نسخهٔ سازگار
برنامه را کامل ببندید؛ ZIP جدید را در پوشه‌ای موقت باز کنید و فقط `app` را با نسخهٔ سازگار جایگزین کنید. `data` را حذف یا جایگزین نکنید. این G0 هیچ تبدیل schema یا ابزار بازیابی ندارد؛ دادهٔ ناسازگار بدون تغییر رد می‌شود. نسخهٔ فعلی app را تا تأیید اجرا نگه دارید.

راهنمای فارسی: `USER_GUIDE.md` در ZIP و صفحهٔ راهنمای داخل برنامه. در مخزن: `docs/USER_GUIDE.md`، معماری در `docs/ARCHITECTURE.md`، وضعیت ادامه در `docs/DEV_HANDOFF.md` و `docs/ROADMAP.md`.

## نتیجهٔ بررسی همین تحویل
۱۵ آزمون ذخیره، ۱۷ سناریوی مرورگر روی منبع و همان ۱۷ روی فایل اجرایی استخراج‌شده، ۹ بررسی کیفیت و ۷ بررسی چرخهٔ ZIP پاس شدند. شواهد JSON و تصاویر در `docs/evidence` هستند. آزمون بسته با داده و مرورگر مستقل انجام شد؛ حساب Windows تازه یا دستگاه دوم آزموده نشده است. زوم ۲۰۰٪ شبیه‌سازی CSS است؛ Narrator واقعی، زوم تنظیمات مرورگر، SmartScreen دانلود اینترنتی و Copy دستی از PDF viewer هنوز باز هستند. متن دو PDF مصنوعی استخراج و با Clipboard واقعی Paste شد؛ پایان‌خط textarea به LF تبدیل می‌شود.
وضعیت G0 پس از تحویل: `waiting_for_owner`. ادامهٔ M1-الف یا هر نوبت دیگر فقط با درخواست صریح مالک مجاز است.
