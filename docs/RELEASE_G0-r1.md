# سیستم مطالعه من — G0-r1

اولین نمونهٔ اجرایی آزمایشی ویندوز؛ فقط تحویل G0.

## اجرا
ZIP را کامل در پوشه‌ای قابل‌نوشتن و خارج از OneDrive استخراج کنید و app/MyStudySystem.exe را اجرا کنید. سپس «ایجاد دادهٔ آزمایشی» را بزنید. Windows 10/11 x64، Chrome/Edge و .NET Framework 4.x لازم است؛ Python همراه بسته است.

## امکانات
ثبت متن فارسی و انگلیسی، تقویم شمسی، ذخیره و بازگشایی، مطالعهٔ دو کتاب ساختگی، گزیده و نشانگر صفحه، جست‌وجو، مرور نمایشی، دو تم و خروج کامل.

## آزمون‌های انجام‌شده
۱۵ آزمون ذخیره‌سازی، ۱۷ آزمون مرورگر روی منبع و مجدداً ۱۷ روی بسته، ۹ آزمون کیفیت و ۷ آزمون چرخهٔ بسته موفق بودند. ۲۴ ترکیب نمایش بررسی شد. جزئیات در docs/TEST_MATRIX.md است.

## محدودیت‌ها
فقط دادهٔ آزمایشی وارد کنید. نتیجه‌های مرور نمایشی‌اند. پیش‌نویس ذخیره‌نشده در خرابی مرورگر تضمین ماندگاری ندارد. Narrator، زوم واقعی مرورگر، دستگاه دوم و SmartScreen دانلود واقعی هنوز بررسی دستی نشده‌اند. فایل اجرایی امضای تجاری ندارد. صوت و بکاپ/بازیابی طبق درخواست مالک به انتهای فاز آخر منتقل شده‌اند.
