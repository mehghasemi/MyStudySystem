# ADR 001 — نمونهٔ محلی G0

> وضعیت: پیش‌نویس تاریخی پیش از اصلاح اولویت؛ بخش‌های صوت و بکاپ/Restore این تصمیم با PRD ۳٫۱۲ لغو و به G5-پایانی منتقل شده‌اند. برای G0 پیاده‌سازی یا ابزارسازی آن‌ها ادامه نیابد. انتخاب PyInstaller نیز به علت تکمیل‌نشدن نصب هنوز اثبات نشده؛ runtime و بسته‌بندی باید با آزمون واقعی نهایی شوند. مرجع وضعیت: ../DEV_HANDOFF.md و ../ROADMAP.md. متن زیر سابقهٔ تصمیم اولیه است، نه دامنهٔ جاری تحویل.

تاریخ: ۱۴۰۵/۰۸/۱۵. دامنه فقط G0، بدون مدل کامل فازهای آینده.

Python استاندارد + SQLite + رابط HTML/CSS/JavaScript و بستهٔ PyInstaller onedir انتخاب شد. در برابر Node/React یا .NET، این گزینه برای سه مسیر آزمایشی وابستگی زمان اجرای کمتری دارد؛ Python و SQLite داخل app همراه‌اند. مرورگر Chrome/Edge دستگاه پیش‌نیاز است. HTTP فقط 127.0.0.1 با پورت آزاد، Host و Origin دقیق، کوکی تصادفی جلسه و توکن CSRF؛ حساب خصوصی Windows مرز اعتماد است. وب‌سرور تک‌درخواستی برای این نمونه کافی است؛ پخش فایل با قطعه‌های محدود حافظه انجام می‌شود و در F1 بار هم‌زمان باید بازبینی شود.

مالک داده Store است؛ ذخیره با revision و operation_id در یک تراکنش. پشتیبان با SQLite backup API، هش و manifest؛ Restore در staging، بررسی schema، snapshot بازیابی و جایگزینی اتمی پس از بستن اتصال. قفل سیستم‌عامل روی data از دو فرایند نویسنده جلوگیری می‌کند. فایل‌ها فقط زیر ریشهٔ تأییدشده قابل خواندن‌اند؛ حرکت پوشه در G0 غیرفعال است.

مرور G0 صرفاً آشکارسازی و پیش‌نمایش سه نتیجه است؛ برنامه‌ریزی، سهمیه و Undo مربوط به M1-ب هستند. انتخاب تاریخ و متن در نمونه واقعاً ذخیره می‌شوند. هیچ اسکلت ماژول آینده ساخته نمی‌شود.

طرح دیداری: محیط آرام مطالعه با زمینهٔ مه‌آبی #F3F6FA، کاغذ سفید #FFFFFF، جوهر #172B46، تأکید آبی #2459A9، متن فرعی #53657C و خطای #A32638. تم تاریک معادل با زمینه #121D2E و متن #E6EDF8. وزیرمتن محلی و ایران‌سنس در صورت نصب؛ متن مطالعه با عرض ۶۶ نویسه و فاصلهٔ سطر ۲٫۱. ناوبری راست، مرکز صفحه مخصوص عمل جاری، منابع فرعی جمع‌شدنی. از آمار تزئینی و شبکهٔ کارت‌های یکسان صرف‌نظر شد؛ نشانگر صفحهٔ کتاب و حاشیهٔ خواندن عنصر شاخص هستند. توکن‌ها در app/static/style.css مشترک هر سه مسیرند.
