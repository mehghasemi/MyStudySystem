# ADR 002 — بستهٔ آفلاین و دامنهٔ جاری G0

تاریخ ۱۵ آبان ۱۴۰۵؛ جایگزین تصمیم‌های اجرایی ADR 001 پس از اصلاح اولویت به PRD ۳٫۱۲.

## تصمیم و دلیل
Python 3.14.7 استاندارد همراه بسته، SQLite 3.50.4، رابط بدون framework و راه‌انداز C# کوچک با .NET Framework موجود در Windows. runtime از نصب محلی شناخته‌شده، با Python exe/dll، ماژول‌های لازم و zip استاندارد ساخته می‌شود؛ ._pth مسیرها را ایزوله می‌کند. محصول به Python سیستم، pip، Node یا اینترنت وابسته نیست. وابستگی .NET Framework برای راه‌انداز در README تصریح شده است.

PyInstaller بررسی شد اما نصب آن به‌علت timeout شبکه کامل نشد. به‌جای وابسته‌کردن تحویل به دریافت ابزار جدید، راه‌انداز محلی با compiler موجود ساخته شد. Electron/React/Node runtime برای سه مسیر G0 هزینهٔ توزیع بیشتری داشت و فعلاً انتخاب نشد. اگر این runtime در دستگاه دوم یا خط‌مشی سازمانی ناسازگار باشد، بسته‌بندی باید با شاهد جدید بازبینی شود؛ امضای تجاری تهیه نشده است.

پخش، FFmpeg، فایل صوتی، بکاپ، Restore و migration از کد G0 حذف شدند. فقط ذخیرهٔ تراکنشی و رد دادهٔ خراب/ناسازگار باقی است. schema=2 شمارهٔ داخلی اولین بسته است و تعهد مهاجرت از پروتوتایپ منتشرنشده نیست.

## طراحی مشترک
مه‌آبی #F3F6FA، کاغذ #FFFFFF، جوهر #172B46، متن فرعی #53657C، آبی #2459A9 و خطا #A32638؛ در تاریک زمینه #121D2E، کاغذ #1B2A40، متن #E6EDF8 و تأکید #A8C9FF. کنتراست متن توکن‌های اصلی در هر دو تم اندازه‌گیری و حداقل ۴٫۵ تأیید شد. وزیرمتن محلی، سطر مطالعه حداکثر ۶۶ch و ارتفاع سطر ۲٫۱. منوی راست و فضای مرکزی مخصوص عمل جاری؛ در عرض مؤثر کم، ناوبری به ردیف بالای محتوا تبدیل می‌شود و هیچ کنترل شناوری متن را نمی‌پوشاند. کتاب نمونه و حاشیهٔ مطالعه جای آمار تزئینی را گرفته‌اند.

## شواهد
۱۵ آزمون ذخیره؛ ۱۷ سناریوی مرورگر روی منبع و همان ۱۷ روی EXE استخراج‌شده؛ ۹ بررسی کیفیت و ۷ بررسی چرخهٔ ZIP. جزئیات و محدودیت‌ها در TEST_MATRIX. تست چرخه با PATH فاقد Python سیستم، cwd متفاوت، تعویض app، DB فقط‌خواندنی و schema آینده انجام شد.
